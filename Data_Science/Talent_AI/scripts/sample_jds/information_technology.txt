Information Technology Specialist

We are looking for an IT professional to support and maintain our organization's
computing infrastructure. Responsibilities include system administration, network
administration, troubleshooting hardware and software issues, and maintaining
cybersecurity best practices.

Required skills:
- System administration and network administration
- Linux and Windows server environments
- SQL and database management (MySQL, PostgreSQL, or Oracle)
- Cybersecurity fundamentals
- Git version control
- Cloud platforms (AWS or Azure)
- Strong problem solving and communication skills

Preferred:
- Experience with Docker and CI/CD pipelines
- Scripting in Python

This role requires attention to detail, adaptability, and the ability to work
independently on infrastructure projects.
